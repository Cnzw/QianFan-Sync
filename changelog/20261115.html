修复优化

把"看似成功、实则丢失"连根拔掉

✓

修复:百家号视频标题变成文件名

「新增智能文案」推广气泡锚定在描述编辑器上方拦截点击,焦点进不去;而百家号会把视频文件名预填进描述框(videoV2 无独立标题框,平台标题=描述)——最终作品标题变成文件名。现四重防护:点掉气泡 → 点击后校验聚焦 + focus() 兜底 → 清掉预填再输入 → 输入后校验编辑器文本,不符留截图并报错。

气泡自动关闭 聚焦校验 填充结果验证
✓

修复:快手作品关联不上同名作品

快手发布页没有标题概念(平台标题=描述+#话题),同账号存在多条同描述作品时,旧的"多命中即放弃"规则导致永远绑不上。现改为收紧到发布完成时间 ±2 天窗口、取时间最近的一条;超窗旧作品与时间不可解析的作品仍拒绝绑定,防误绑。

时间就近匹配 时间窗防误绑
✓

修复:微博图集作品无法关联

微博作品抓取此前只实现视频类型,图集请求直接返回空。现扩展支持图集:抓取个人主页全部微博中带图稿件,标题取正文(图集无标题概念),播放/点赞/评论/转发解析对齐视频稿件。经真实账号验证绑定成功。

图集稿件识别 真实账号验证
✓

修复:快手图集超 31 张卡死

快手图集单次最多 31 张(发布页文案实证),超限时上传区报错、编辑页永不出现,流程异常又被静默吞掉——浏览器挂在页面无反应。现超限自动丢弃超出部分(保留前 31 张)并提示;流程异常全部落日志 + 现场截图;编辑页等待放宽到 120 秒。

超限自动截断 异常落日志+截图
✓

修复:图集发布历史一直不可见

历史列表默认过滤旧版本数据(批次需含新版封面字段或来源标记),而图集发布两样都没有——所有图集记录从上线起就被静默过滤。已补写来源标记并一次性找回存量记录;同时图集未单独选封面时,取图集首图作为列表卡片封面。

存量记录找回 首图兜底封面
✓

修复:B 站发布时话题搜索不执行

发布过程中打开「搜索更多话题」弹层后,此前只在默认候选里找精确文本,从不输入关键词——推荐列表之外的话题必然落空。现补全为弹层内输入话题名触发搜索,等结果渲染后精确匹配选中并关闭弹层,已实测选中推荐外话题。

弹层输入搜索 等待结果再选中
✓

修复:图集发布面板无边框

快手 / 微博 / 支付宝 / 抖音四平台图集面板的样式块写成纯 CSS 却引用了 SCSS 变量——边框与底色从未生效过。已统一改为 SCSS 块并引入变量,卡片与发布中心视觉规格一致。

四平台一次修复
✓

优化:发布页头部按钮统一

视频发布页头部普通按钮与主发布按钮高矮不一(32px vs 40px),观感突兀。三个发布页(视频 / 图文 / 文章)头部按钮统一为 40px 高,主按钮渐变阴影对齐;文章页补齐缺失的主按钮渐变样式,小屏自适应保留。

三页统一 40px 小屏自适应
✓

修复:作品同步完成无提示

作品详情页同步完成的 toast 因参数缺失从未弹出(完成回调漏传消息类型),已修复——同步结束明确弹出「数据同步完成」;发布历史「关联数据」弹窗说明同步范围,详情页操作按钮风格统一。

toast 修复 按钮风格统一
